Aviso de privacidad

Esta aplicación se usa para enviar y recibir mensajes de WhatsApp con clientes a través de la API oficial de WhatsApp Business.

Datos que se tratan: número de teléfono, nombre de perfil de WhatsApp y el contenido de los mensajes intercambiados.

Para qué: únicamente para atender y dar seguimiento a la relación con cada cliente. Los datos no se venden ni se comparten con terceros, salvo con Meta como proveedor del servicio de WhatsApp.

Baja: cualquier persona puede dejar de recibir mensajes respondiendo «BAJA» en el chat.

Eliminación: puedes solicitar que se eliminen tus datos respondiendo en el mismo chat de WhatsApp.
